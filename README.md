## 概要
敵と戦い武器やスキルをパワーアップしていき攻略を目指す3Dローグライクゲームです。

**ジャンル:** 3Dローグライク
*   **プレイ人数:** 1人
*   **プレイ時間:** 1時間程度
*   **ターゲット層:** ローグライクゲームが好きな方

## 特徴・アピールポイント
*   ポイント1：複数のアイテムの実装
*   ポイント2：プレイヤーのスキル実装
*   ポイント3：バフデバフ効果やプレイヤーのステータス変動の実装
*   ポイント4：プレイヤーのアップグレード要素実装

## 遊び方（操作方法）
### 操作方法
#### [戦闘時]
*   **移動:** `W` `A` `S` `D`
*   **回避:** `LeftShift` キー
*   **通常攻撃:** `左クリック`
*   **防御:** `右クリック`
*   **スキル攻撃:** `Q` `E` `R` `F`
*   **ポーション使用:** `1` `2` `3`
*   **ポーズ:** `Tab` キー

#### [ショップ時]
*   **アイテム操作:** `左クリックドラッグ＆ドロップ`
*   **ショップアイテム保留:** `右クリック`

### ルール
1. ルール：2つのジョブから選択して、ショップ入店時にもらえるお金を使用して装備を強化したりスキルをレベル上げて10ラウンド勝ち続ける。

## 導入手順・起動方法
1. 本リポジトリの [Releases](https://github.com/Kurama-Hiiti/GladiatorArena/releases) からGLADIATOR.ARENA.zipファイルをダウンロードします。
2. ダウンロードしたファイルを解凍します。
3. `GLADIATOR ARENA.exe` を実行するとゲームが始まります。

**[UnityRoom](https://unityroom.com/games/gladiatorarena)にもアップロードしているのでそちらからもプレイできます。**
